# Penned by Ella

A modern editorial portfolio website for **Emmanuella Olong**, a Nigerian freelance writer, health communicator, and student pharmacist.

The website presents her writing, health communication work, creative projects, services, personal brand, social platforms, and Substack publication in a visually engaging digital portfolio.

---

## ✦ About the Project

**Penned by Ella** is a personal brand and portfolio website designed to showcase Emmanuella Olong's work as a writer and health communicator.

The website combines an editorial-inspired visual identity with modern responsive web design.

The design is built around the idea that writing is more than text — it is a way to communicate ideas, tell stories, explain complex subjects, and connect with people.

### Brand positioning

> Writer · Health Communicator · Student Pharmacist

## ✦ Brand & Design

The visual identity takes inspiration from editorial publishing, modern personal branding, and literary design.

### Primary palette

| Color | Hex |
|---|---|
| Warm Cream | `#F7F0E5` |
| Cream Light | `#FFFAF2` |
| Espresso | `#241509` |
| Brown | `#4A2D1A` |
| Caramel | `#C58A52` |
| Gold | `#D2A06B` |
| Burgundy | `#7D302C` |
| Muted Blue | `#344A5E` |

The primary visual combination is **warm cream + espresso brown**, with caramel, gold, and burgundy used as restrained accents.

---

## ✦ Typography

The website uses two complementary typefaces:

### Display

**DM Serif Display**

Used for large editorial headings and major statements.

### Body

**Inter**

Used for navigation, descriptions, buttons, labels, and supporting text.

## ✦ Tech Stack

This project is intentionally lightweight and uses:

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- CSS Grid
- CSS Flexbox
- Intersection Observer API
- HTML5 Video
- Schema.org structured data

No frontend framework is required.
